# Handoff notes — M4

Status: M1–M4 are implemented against **1.8.9 / protocol 47** and covered by the test suite.
Version `0.7.0`. M1–M3 were verified live on PikaNetwork; M4's live gate (a 10-minute anti-cheat

## Shape of the state

- `PhysicsEngine.step(state, controls, world)` is **pure**: it returns a new frozen `PlayerState` and
  performs no I/O. It reads only `block_at` and `collision_boxes`.
- `PlayerState.position` is the feet position. Medium flags describe the position **after** the tick
  and feed the next tick. `on_ground` comes from the last collision.
- The bot creates one `TickDriver` when the first `position` packet arrives. The loop:
  1. returns early to confirm a pending teleport,
  2. returns early while dead or the current chunk is unloaded,
  3. steps physics, syncs sprint/sneak `entity_action`, sends at most one movement packet,
  4. dispatches `PhysicsTickEvent`.
- `Bot.close()`, a reconnect, or `_close_client()` stops and cancels the physics task. Respawn resets
  `physics_state`, controls, the movement baseline and the sent action flags.
- 1.8 has no teleport id: the confirmation is a `position_look` echo on the tick after the server
  position. 1.9+ sends `teleport_confirm` with the id. The confirmation tick does not simulate, so
  two movement packets are never sent in one tick.
- Movement cadence is owned by `MovementTracker`: squared delta > `4e-8`, rotation epsilon `1e-5`,
  ground-flag flips, and a 20-tick reminder. Precedence is `position_look` → `position` → `look` →
  `flying`.
- Sprint/sneak changes are sent as `entity_action` **before** the movement packet that uses them.

## Physics invariants

- Collision clips Y, then X, then Z and translates the whole hitbox; it never shrinks the `0.6` wide
  box.
- Ground friction is `slipperiness * 0.91`; ground acceleration is
  `speed * 0.1627714 / friction³`; air acceleration is `0.02` (`1.3x` while sprinting).
- Ladders climb on horizontal collision (`0.2`), not on jump. Sneaking holds them with
  `velocity.y >= 0`.
- Cobwebs scale the movement delta by `(0.25, 0.05, 0.25)` and then zero velocity.
- `TickDriver` uses absolute deadlines. More than `max_catch_up` intervals behind means the oldest
  backlog is dropped, not burst. Normal sub-millisecond wakeup lateness is not a catch-up.

## Verification

```bash
source .venv/bin/activate
python -m pytest tests/test_physics.py tests/test_physics_oracle.py tests/test_movement.py -q
# 35 passed
python -m pytest -q
# full suite (see the session log for the final count)
python examples/physics_demo.py
```

- Ten oracle traces (walk, sprint, sneak, jump, sprint jump, ice, slime, cobweb, water, lava) match
  prismarine-physics 1.11.1 within `1e-6` per tick for position, ground and liquid flags.
- Stairs, ladder climb/sneak hold, soul-sand slowdown and 300 seeded invariant ticks are covered by
  `tests/test_physics.py`.
- Movement cadence, teleport confirmation, `entity_action` ordering and one-tick jumps are covered
  by `tests/test_movement.py` over `FakeServer` and `FakeClock`.
- Idle real-clock measurement: **19.994 TPS**, p99 jitter **0.83 ms**, 0 dropped, 0 catch-up over
  103 ticks (gate p99 < 5 ms).

## Divergences and deferred work

- **Soul sand** uses vanilla supporting-block slowdown; prismarine 1.8 does not implement it, so it
  is excluded from the oracle and unit-tested instead.
- **Honey** is 1.15+; deferred with the first 1.15+ dataset (1.8 has no honey block).
- **Stairs/ladders** need per-metadata shapes; the synthetic oracle world does not build them, so
  they run against the vendored 1.8 collision data.
- **Effects/attributes**, flight/elytra, liquid exit impulse and bubble columns are not modelled.
- The local player's server velocity packets are not applied; reconciliation is position/teleport
  only.
- Physics pauses while the current chunk is unloaded instead of falling through terrain.
- `ruff`, `mypy`, `pyright` and `import-linter` are still unavailable in this Python 3.14
  environment; the test suite is the verification gate that ran here.
- The 10-minute live anti-cheat soak remains open.
