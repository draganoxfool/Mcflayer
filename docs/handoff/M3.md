# Handoff notes — M3

Status: M1–M3 are implemented against **1.8.9 / protocol 47**, covered by the test suite and verified
live on PikaNetwork. Version `0.6.0`.

## Public symbols added

- `pyflayer.world`: `World`, `WorldSnapshot`, `Bounds`, `ChunkColumn`, `ChunkSection`, `section_index`,
  `PalettedContainer`, `ContainerKind`, `BlockState`, `Entity`, `EntityTracker`, `RayHit`, `raycast`,
  `ChunkStore`, `WorldKey`.
- `pyflayer.bot.inventory`: `Inventory`, `Window`, `PLAYER_WINDOW`, `HOTBAR_START`, `HOTBAR_SLOTS`.
- `Bot` slots: `world`, `entities`, `inventory`, `experience` (`(bar, level, total)`), `attributes`

  `EntityMoveEvent`, `EntityGoneEvent`, `EntityMetadataEvent`, `InventoryChangedEvent`,
  `DimensionChangeEvent`, `ExperienceEvent`.

- Top-level re-exports: `World`, `WorldSnapshot`, `ChunkColumn`, `ChunkSection`, `PalettedContainer`,
  `BlockState`, `Entity`, `EntityTracker`, `RayHit`.

## Shape of the state

- `World` is mutable and only touched on the event loop; `WorldSnapshot` is a cheap copy for worker
  threads. Sections are immutable, so a block write replaces one section and bumps the column
  `version`.
- `BlockPos.chunk` selects the column; block state ids are 1.8 `(block_id << 4) | metadata`.
  `block_state_id()` raises `ChunkNotLoaded`/`OutOfWorldBounds`; `block_state_id_or()` takes a default.
- `Bot` handlers mutate world/entities/inventory **before** dispatching the event (ADR-4).
  `InventoryChangedEvent.slot == -1` means the whole window was replaced.
- Respawn and dimension change clear the world and entities; inventory persists, as in vanilla.
- `ChunkStore` (refcounted columns) is for M7; a single `Bot` uses `World` directly.
- The packet registry compiles all 74 play/toClient and 26 play/toServer packets for 1.8.9.
- The `slot` type resolves to the native `ItemStack` codec; do not expect raw `blockId` dicts from
  `PacketRegistry.decode()` or `FakeServer` packets.

## Deferred intentionally

- Modern global block-state tables (`minStateId`/`maxStateId`) and 1.13+ chunk sections; only
  synthetic `PalettedContainer` coverage exists.
- Chunk batches (`chunk_batch_start/finished`, 1.20.2+).
- Typed block entities (raw NBT today), client-side lighting.
- Chunk data from other dimensions, unload confirmations beyond the 1.8 packet.
- Mineflayer oracle fixtures and the 441-column memory benchmark.
- `ruff`/`mypy`/`pyright`/`import-linter` are still not installed in this Python 3.14 environment;
  the test suite is the verification gate that ran here.
