# Handoff notes — M1

## Public symbols added

- `pyflayer.errors`: full tree (`PyFlayerError`, `ProtocolError` and subclasses, `ConnectionClosed`,
  `DataError`, `MissingRegistryEntry`, `UnsupportedVersion`, `UnsupportedType`, …).
- `pyflayer._internal`: `Clock`, `MonotonicClock`, `FakeClock`, `run_cpu`.
- `pyflayer.models`: `Vec3`, `BlockPos`, `ChunkPos`, `SectionPos`, `AABB`, `ChatComponent`,
  `ItemStack`, enums, Protocols.
- `pyflayer.data`: `McData`, `Features`, `VersionInfo`, registries, `ShapeTable`, version helpers.
- `pyflayer.protocol`: `PacketReader`, `PacketWriter`, `FrameCodec`, `CipherPair`, `Connection`,
  `PacketRegistry`, `Packet`, `ProtocolCompiler`, `ping`, `ServerStatus`, VarInt helpers.

## Invariants M2 may rely on

- Everything in `errors` and `models` is import-safe and pure.
- `PacketReader` methods raise only `MalformedPacket` on bad bytes; `ensure_finished()` is strict by
  default.
- `PacketRegistry.decode()` raises `UnknownPacket` with `raw` = payload after the packet id.
- `Connection.read_payload()` returns one complete payload with decryption/inflate applied;
  compression/encryption changes happen at frame boundaries via `set_compression()` /
  `enable_encryption()`.
- `McData` and registries are immutable and cached; safe to share across tasks/threads.
- `FakeClock.advance()` is synchronous; use `advance_async()` when awakened tasks must run.

## Deferred intentionally

- `ProtocolClient`, auth, events, bot (M2).
- Entity metadata native codec: `entity_metadata`, `named_entity_spawn`, `spawn_entity_living`,
  `world_particles` do not compile for 1.8 play/toClient yet.
- Modern block-state tables and structured item components.
- Hypothesis property tests and the lint/type toolchain run (environment could not install ruff on
  Python 3.14).
