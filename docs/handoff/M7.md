# Handoff notes — M7

Status: M1–M5 and M7 are implemented against **1.8.9 / protocol 47** and covered by the test suite.
M6 (A* pathfinder, action scheduler, actions) is still design-only. Version `0.9.0`.
The M4 live anti-cheat soak and the M7 50-bot Paper soak remain environment-dependent gates.

## Invariants the next milestone may rely on

- `SharedWorld` implements the `World` read/write surface used by the bot and physics. A view only
  sees chunks in its own held set; reads/updates outside it raise `ChunkNotLoaded` / return `False`.
- The first decoded column wins; later identical copies add a ref only. `ChunkStore.put` is
  idempotent by version, `replace` never changes refcounts, `release_all`/`release` collect at zero.
- `SharedWorld.set_dimension` releases the old dimension's refs before rebinding.
- `ClaimRegistry` claims are block/region-wide, TTL on the injected clock, all-or-nothing for
  regions, and `release_owner` is called on `DeathEvent`/`DisconnectEvent` by the cluster.
- `Blackboard` change events are dispatched through its own `EventBus`; `wait_for` returns the new
  value.
- Cluster supervisors own reconnect policy (`Bot(reconnect=False)` inside a cluster). One bot's
  kick/exception never cancels another. `remove_on_kick=True` retires non-throttle kicks;
  throttle kicks use `LoginStaggerPolicy.record_throttle` and retry.
- Tick groups distribute bots round-robin over 20 TPS `TickDriver`s. `tick_budget_ms` p99 overflow
  adds a group up to `max_tick_groups` and sets `ClusterMetrics.degraded`.
- `stop()` releases chunk refs, cancels supervisors and driver tasks, closes bots and the cluster
  bus. No fire-and-forget tasks are left.

## Fixed while verifying M7

- `protocol/protodef.py`: parameterized **native** types (`container`, `switch`, `array`, `option`,
  `bitfield`, `bitflags`, `mapper`, …) were routed through the named-type path, dropping their
  parameters. Every container decoded to `{}`; login and play packets were unusable. Native specs
  now keep their params, and a non-native named type still uses `_compile_parametrized`.
- `protocol/protodef.py`: `_BitfieldCodec.write` now accepts `BlockPos`/`Vec3` for the 1.8
  `position` bitfield as well as the decoded `{x, y, z}` dict.
- `testing/fake_server.py`: `stop()` closes accepted connections before awaiting
  `Server.wait_closed()` (Python 3.13+ waits for active connections, which deadlocked teardown).
- `tests/test_data.py`: the "unsupported version" test now uses `1.99.9`; `1.20.4` data is present
  in the working tree.

## Deferred / limitations

- M6: no planner or action scheduler, so claims/roles/path cache are primitives for callers, not
  automatically consumed.
- No shared Microsoft token cache or injected `httpx.AsyncClient`; auth remains per-bot.
- Cross-process sharding, block-claim re-validation mid-action and a 50-bot soak are out of scope.
- `LoginStaggerPolicy` only infers throttling from kick text; tune `min_interval` per host.
