## Dispatch invariants

- **No prefix.** `commands.Bot(command_prefix=...)` raises `CommandPrefixError` (a `TypeError`).
  There is no prefixed parsing path anywhere in the codebase.
- A message is addressed when it is a whisper, when the bot's name appears as a non-alphanumeric
  token, when `trigger=` matches, or via `dispatch_command`. Server/system lines (`sender is None`)
  and the bot's own lines are ignored.
- `process_message` runs from a `ChatEvent` listener; `dispatch_command` bypasses address rules and
  is the entry point for tests, cogs and a REPL.
- Errors travel `bot.on_command_error` → `cog.cog_command_error` → `@command.error`; the first that
  returns stops the chain.
- `ctx.reply()` whispers when the invocation was a whisper, otherwise chats publicly. All outbound
  text goes through `ChatQueue` (1.1 s / burst 3 / 256-char split).

## Extension invariants

- `load_extension` records every command and cog added during `setup` in a per-extension ledger.
  If setup raises, the ledger is rolled back: commands removed, cog listeners unsubscribed, loops
  cancelled, cogs dropped, and `ExtensionFailed` raised.
- `unload_extension` calls `teardown`, removes cogs (which cancels loops and unsubscribes owners),
  removes ledger commands, then purges the extension's `sys.modules` subtree.
- `reload_extension` is atomic. On failure it re-adds the saved cogs and commands, restores the old
  module in `sys.modules`, re-registers the extension entry, and raises `ExtensionFailed`.
- A 20-cycle reload loop leaves `events.subscription_count`, `len(bot.commands)` and
  `events.task_count` unchanged.

## Loops

- `tasks.loop(ticks=N)` waits on `N` `PhysicsTickEvent`s between iterations; without a bot it
  falls back to `N / 20` seconds on the injected clock.
- Wall-clock loops use the bot's `Clock`; `FakeClock` makes them deterministic.
- Cogs resume started loops on `add_cog` and cancel them on `remove_cog`.
- `count=N` stops after `N` iterations.

## Deferred / limitations

- Public-chat addressing is token-based; plugin chat that rewrites names needs `trigger=`.
- `tasks.loop(time=…)` is accepted but not scheduled; reconnect pausing is not wired to
  `DisconnectEvent`.
- `Union`/`Optional` conversions are supported, but `Member`/`Role`/permission converters have no
  Minecraft analogue and are absent.
- `Instance`-level `@bot.command` inside a cog body is not supported; use `@commands.command`, which
  `CogMeta` collects.
- No slash commands, interactions, views, webhooks, permissions or feature parity (ADR-11).
- `ruff`/`mypy`/`pyright`/`import-linter` are still unavailable in this Python 3.14 environment; the
  test suite is the verification gate that ran here.
