# Handoff notes — M2

Status: M1 and M2 are implemented against **1.8.9 / protocol 47**, verified live on PikaNetwork.

## Public symbols added

- `pyflayer.protocol.state`: `ConnectionState`, `StateMachine`, `LEGAL_TRANSITIONS`.
- `pyflayer.protocol.auth`: `Session`, `AuthProvider`, `StaticAuth`, `OfflineAuth`, `offline_uuid`,
  `validate_username`, `MicrosoftAuth`, `server_hash`, `join_session`.
- `pyflayer.protocol.client`: `ProtocolClient` (`connect`, `packets`, `read_packet`,
  `send_packet`, `send_chat`, `close`, `state`, `session`, `encrypted`, `compression_threshold`).
- `pyflayer.events`: `Event`, `EventBus`, `Subscription`, `Expectation`, `event_for_name` and the
  catalog `ConnectEvent`, `LoginEvent`, `JoinEvent`, `SpawnEvent`, `RespawnEvent`, `DeathEvent`,
  `HealthEvent`, `ChatEvent`, `PlayerInfoEvent`, `KickEvent`, `DisconnectEvent`, `ErrorEvent`.
- `pyflayer.models`: `ChatMessage`; `ConnectionState` gained `CONFIGURATION` and `CLOSED`.
- `pyflayer.bot`: `Bot`, `BotState`, `PlayerInfo`, `ChatQueue`, `parse_chat_json`, `split_message`.
- `pyflayer.testing`: `FakeServer` (encryption, compression, chat/keep-alive/respawn echo, kicks).
- CLI: `pyflayer-connect` / `python -m pyflayer.cli`.

## Invariants M3 may rely on

- A successful `await ProtocolClient.connect()` leaves the state machine in `PLAY`; `packets()`
  yields decoded play/toClient packets and skips unknown/unsupported ones (counted in
  `skipped_packets`, ids in `unknown_packet_ids`). It never raises for an unimplemented packet.
- `Bot.connect()` returns the `JoinEvent`; the settings packet has already been sent and later
  packets are consumed by `Bot.run()`. `Bot.wait_until_ready()` is set at Join Game.
- `EventBus.dispatch` is synchronous, resolves waiters first, runs priority ≥ 1000 listeners inline,
  and schedules other listeners as tracked tasks. `expect()` registers its waiter synchronously, so
  it cannot miss an event dispatched immediately after entering the context.
- `Bot` handlers mutate bot state before dispatching the corresponding event (ADR-4 shape).
- `KickedError` leaves `Bot.run()` after `KickEvent` + `DisconnectEvent`; `ConnectionClosed` is
  retried only when `reconnect=True`.
- `McData` is cached and immutable; `ProtocolClient` owns one registry per connection.

## Deferred intentionally

- World/chunk/entity metadata/inventory state (M3). Chunk and entity packets are skipped, not fatal.
- Configuration state for 1.20.2+ (code path reserved; no data yet).
- Microsoft auth has no on-disk token cache (the refresh token is kept in memory); not live-tested.
- Signed chat, 1.19+ chat sessions.
- `ruff`/`mypy`/`pyright`/`import-linter` runs in this environment.
